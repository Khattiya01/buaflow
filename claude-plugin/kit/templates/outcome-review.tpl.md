> เพิ่ง release ไม่กี่วัน) ให้เขียนว่า "ยังวัดไม่ได้ — นัดทบทวนอีกครั้งวันที่ ..." แล้วเลือก decision เป็น `monitor`
> อย่าใส่ตัวเลขเดาเพื่อให้ตารางดูสมบูรณ์

## การตัดสินใจ

เลือกหนึ่งข้อ พร้อมเหตุผล:

- [ ] **keep** — บรรลุ target แล้ว ไม่ต้องทำอะไรเพิ่ม ปิด initiative นี้
- [ ] **iterate** — ทิศทางถูกแต่ยังไม่ถึง target ต้องปรับต่อ (เปิด task/intent ใหม่สำหรับรอบถัดไป)
- [ ] **rollback** — แย่กว่าก่อนแก้ หรือสร้างปัญหาใหม่ที่หนักกว่าเดิม ต้องย้อนกลับ
- [ ] **monitor** — ยังสรุปไม่ได้ ข้อมูลไม่พอ ต้องรอวัดต่อ (ระบุวันนัดทบทวนใหม่)
- [ ] **open-new-intent** — ระหว่างทบทวนเจอปัญหาอื่นที่ initiative นี้ไม่ได้ตั้งใจแก้ แยกเป็นงานใหม่
