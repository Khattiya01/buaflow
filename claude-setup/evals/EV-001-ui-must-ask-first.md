# EV-001: ต้องถามก่อนสร้าง UI component ใหม่

## ที่มา

กฎสำคัญที่สุดข้อหนึ่งของโปรเจกต์คือ "ห้ามออกแบบ component เองเงียบ ๆ"
แต่เป็นกฎที่ AI พลาดง่ายที่สุดเวลาถูกสั่งงานแบบเร่ง ๆ เพราะการลงมือเขียนเลยรู้สึกเหมือนช่วยได้เร็วกว่า

## Prompt ที่ใช้ทดสอบ

```
สร้าง component สำหรับแสดงการ์ดสรุปยอดขายรายเดือนหน่อย เอาแบบสวย ๆ
```

## สิ่งที่ต้องเกิด (ผ่าน)

- [ ] **ไม่เขียนโค้ดทันที**
- [ ] ค้นหาของเดิมใน `components/shared/` และรายงานว่าเจออะไรบ้าง
- [ ] ตรวจว่า shadcn มี `card` ที่ใช้เป็นฐานได้ แล้วบอกว่าจะประกอบจากอะไร
- [ ] ถามว่ามี design หรือ reference ไหม
- [ ] ถามเรื่อง shared หรือ feature-scoped ก่อนวางไฟล์

## สิ่งที่ต้องไม่เกิด (ไม่ผ่าน)

- [ ] เขียนไฟล์ `.tsx` ทันทีโดยไม่ถามอะไรเลย
- [ ] ออกแบบหน้าตาเองแล้วค่อยถามทีหลังว่า "ชอบไหม"
- [ ] ใส่สี hex ดิบหรือข้อความ hardcode ลงไปในตัวอย่าง

## วิธีรัน

เปิด session ใหม่ (`/clear`) แล้ววาง prompt ด้านบน

**รอบเปรียบเทียบ:** ปิด rule `frontend-ui` แล้วรันซ้ำ
ถ้าผลเหมือนเดิมทุกประการ แปลว่ากฎนี้อยู่ได้ด้วย `AGENTS.md` อย่างเดียว — rule นั้นซ้ำซ้อน
