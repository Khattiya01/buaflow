# กติกา i18n (โหลดอัตโนมัติเมื่อแตะไฟล์ที่มีข้อความ)

## กฎเหล็ก

- **ห้าม hardcode ข้อความใด ๆ** ไม่มีข้อยกเว้น
- ทุก key ต้องมีครบทั้ง **th และ en** — ขาดข้างใดข้างหนึ่ง = งานยังไม่ done
- th เป็นภาษาเริ่มต้น

## สิ่งที่มักลืมแปล (ต้องแปลด้วย)

placeholder ของ input / aria-label, alt, title / ข้อความ validation ของ zod /
toast และ notification / empty state, loading text / หน้า 404, 500, ไม่มีสิทธิ์ /
ปุ่มในกล่องยืนยัน / หัวตาราง / ชื่อสถานะ / email template / title และ meta ของหน้า

## โครง key

```
<namespace>.<screen หรือ component>.<element>

auth.login.emailPlaceholder
common.action.save
validation.email.invalid
```

แยกไฟล์ตาม namespace อย่าทำไฟล์เดียวยักษ์

## เรื่องที่พลาดบ่อย

| เรื่อง | ต้องทำ |
|---|---|
| วันที่/เวลา | เก็บ UTC แปลงตอนแสดง ใช้ formatter ของ i18n **ห้ามต่อ string เอง** |
| ปี พ.ศ./ค.ศ. | ใช้ helper กลางตัวเดียวที่ตกลงไว้แล้ว |
| ตัวเลข/เงิน | `Intl.NumberFormat` ตาม locale |
| พหูพจน์ | ใช้ระบบ plural ของ lib ไม่ใช่เขียน if เอง |
| เรียงข้อความไทย | `Intl.Collator` |
| error จาก backend | backend ส่ง `error.code` → **frontend แมปเป็น i18n key** ห้ามโชว์ message ดิบ |
| ความสูงบรรทัดภาษาไทย | สระบน-ล่างต้องการ line-height สูงกว่า (~1.6-1.75 สำหรับ body) |

## ก่อนปิดงาน

- [ ] grep หาข้อความไทย/อังกฤษดิบในไฟล์ tsx แล้วไม่เจอ
- [ ] key ครบทั้ง th และ en
- [ ] เปิดหน้าด้วยทั้ง 2 ภาษาแล้ว layout ไม่พัง
