# Documentation rules (auto-loaded when touching doc files)

> `node .claude/docs-lint.js` checks artifact-chain consistency (task ↔ intent/spec/plan, leftover markers, WIP, test debt) and runs in the gate —
> the rules below are the part a script cannot check.

## Language

Everything under `docs/` is written in **full Thai** (technical terms, identifiers, code stay English).
These files are read by humans and by other sessions — never apply the terse chat style to them.

## Principle

**The AI treats documents as truth.** If a document lies, the AI writes wrong code, and the error compounds down the chain.
A document that disagrees with the code is more dangerous than no document.

## Never edit — write a new one instead

| File | Why |
|---|---|
| `docs/adr/*.md` once `Accepted` | An ADR is a historical record — to change your mind, write a new ADR that `supersedes` the old one |
| `docs/planning/*.md` | Frozen planning output — changes go into a spec or an ADR |
| `docs/incidents/*.md` already-recorded parts | Append, never rewrite |
| `docs/intents/*.md` that are `rejected` | Kept as the record of why it was turned down |

## Always update together

| Change | Must also update |
|---|---|
| API | `docs/api/openapi.json` + Postman collection |
| Behavior described in a spec | That feature's spec **before** changing the code |
| Component | `docs/design/components.md` |
| Task status | The task file (`docs/backlog/tasks/*.md`) only — `board.md` is generated by `node .claude/board.js`, never hand-edited |
| Architecture decision | New ADR |
| Commands / folder layout / conventions | `AGENTS.md` |
| The AI repeats a mistake (2nd time) | `AGENTS.md` under "Things the AI gets wrong in this project" |

## How to write

- **Short and imperative**, not an essay
- `AGENTS.md` under ~200 lines — beyond that the AI starts skipping items.
  Test for each line: *"If deleted, would the AI get something wrong?"* If not, delete
- Procedures longer than ~30 lines → move to a skill, not into `AGENTS.md`
- Rules tied to a group of files → `.claude/rules/` with `paths:`
- Rules that must never break → need a hook too, otherwise they are not finished
